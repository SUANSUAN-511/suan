1999.12.21 对面搬来了一个男孩子 晴 / 23:11 / 评论(3)

对面0号房搬来了一个男孩子。

说是0号房，其实以前是堆煤的。房东把门牌写成“0”，像给不存在的人留的位置。

他半夜不睡，总把窗户开一条缝。今晚我用镜子反光晃了他三下。

他回了两下。

三下，停，两下。是《信号》的节奏。

我们就这样认识了。

1999.12.24 他说照片是“以后”拍的 雪 / 22:40 / 评论(7)

他在BBS上叫“0”。我们视频了。

他的房间好空，只有一台电脑、一台收音机和一墙的照片。

照片上全是我。

我说你偷拍我？他说不是，是“以后”拍的。

我笑了，骂他神经病。

可有一张照片里，我穿着我还没买的那件红毛衣。

他说，那是2000年1月1日拍的。

1999.12.27 一张2000年的报纸 阴 / 19:05 / 评论(0)

今天收到一张报纸。没有寄件人，邮戳是2000年1月1日。

头条是“红旗路17号火灾，一女失踪”。

配图是烧黑的楼道。失踪者那一栏被墨水涂掉了。

可照片里那件睡衣是我的。

妈妈说是恶作剧。她把它烧了。

灰烬里还剩半张脸。

我把报纸残片夹在日记本里了。下次扫描上来。

1999.12.30 妈妈把电话线拔了 雨 / 23:58 / 评论(2)

妈妈把电话线拔了，说我再上网就把电脑砸了。

我用收音机收到99.9，是阿野的声音。

他一直在重复一句话：“晚晚，零点别来。”

可约我零点见的人明明也是他。

他声音后面，还有一个人在哭。

我把耳机音量调到最大，听见那个哭声说：

“她走了。她往你那边去了。”

我知道那是我妈的声音。她一直在门外。

1999.12.31 最后一篇 · 零点，0号房 雪 / 23:47 / 评论(1999)

我决定了。

今天我十八岁。妈在门口坐了一夜，面坨了，锅里还有饺子。我没吃。

零点，去0号房。

我要问问他，为什么在2000年1月1日的报纸上，我已经死了。

我把这盘磁带留在网站里。

如果有人看到，请帮我按一下播放。

如果我没回来，别关网站。
会有人来的。
